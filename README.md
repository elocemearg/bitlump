# Bitlump

Convert input to integers of different bases, IEEE 754 floating point,
timestamps, bytes, and text.

This is mainly useful during debugging when you see a strange number or bit
pattern and you think "is that a floating point number, or a timestamp,
or a string, or...?"

I originally wrote Bitlump in 2023. It has been hosted at
[https://greem.uk/bitlump](https://greem.uk/bitlump) since then.

Bitlump is made from HTML, CSS and JavaScript. It runs in the browser with no
server-side dependencies once your browser has loaded the page.
